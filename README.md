# 微博超话多账号自动化控制台

这是一个只在本机运行的控制台。它使用独立 Chrome 登录目录管理多个微博账号，并按“轮次 → 超话 → 账号 → 操作段”的顺序串行执行签到、文字发帖和评论。

当前版本：**v1.0.1**（2026-11-02）。本次更新改进发布结果识别、人工验证、页面故障恢复与统计展示；完整变更、兼容性及接口说明见 [CHANGELOG.md](CHANGELOG.md)。

## 安装（Mac / Windows 通用）

1. 从 GitHub Releases 下载 `weibo-console-<版本>.zip` 并解压。
2. Mac：`bash install.sh`；Windows：`powershell -ExecutionPolicy Bypass -File install.ps1`。
3. 打开 http://localhost:4178 ，确认本地服务页面可访问；首次安装显示激活页即完成安装验收。

安装仅准备本地运行环境、启动服务并配置开机自启，不包含扫码登录微博、创建任务或执行签到、发帖、评论。激活软件、输入访问口令、登录账号及运行任务由用户在安装完成后另行决定。

安装脚本会自动准备便携 Node 24、依赖和浏览器；详细步骤与排障见 [INSTALL.md](INSTALL.md)，给 agent 的说明见 [AGENTS.md](AGENTS.md)。

## 主要功能

- 多账号按“轮次 → 超话 → 账号 → 操作段”串行执行签到、文字发帖和评论，操作段数量与间隔可自定义。
- 共享文案库与文案分组；发帖、评论可分别选择文案组。
- 验证码队列：遇到验证码的账号进入待验证队列，由你手动处理；可选定具体操作，验证期间继续观察本次提交结果，同一任务只提醒一次。
- 待验证与待核对分别展示和计数。历史待核对发帖可在任务安全暂停或结束后只读复核，确认成功后同步修正统计与轮次报告，不会重复发送。
- 发帖以本次明确成功回执或新出现的“发布成功／发送成功”提示验收，无需微博编号；评论也支持新出现的“评论成功”提示。旧提示、正文中的成功字样和单独的 HTTP 200 不作为成功证据。
- 自动等待成功结果约 15 秒，人工验证会话可继续观察。普通未确认结果保留待核对并继续后续步骤，不自动翻列表核对或重发；记录页仍可手动复核。
- 记录页：按日统计签到/发帖/评论，一屏查看需要关注的账号、任务明细和流水。
- 断网自动暂停并恢复；每日 23:59 自动停止当天任务。
- 页面加载异常会保留当前步骤，按 5/15/30/60 秒退避只读检查；故障页面连续两次检查通过后自动接续，已提交操作只核验、不自动重发。
- 工作台页头“手机访问”提供二维码，同一 Wi-Fi 下的手机可直接打开。

## 更新与维护

```bash
node bootstrap.mjs update          # 更新程序，保留 data/（账号、文案、激活状态）
node bootstrap.mjs doctor          # 体检：Node / 依赖 / 浏览器 / 端口 / 网络 / 激活
node bootstrap.mjs service install # 开机自启（Mac launchd / Windows 计划任务）
```

从 v1.0.0 更新后，首次启动会自动补充数据库字段并迁移旧的待验证展示状态，无需重新添加账号或扫码登录。请先在页面安全暂停当前任务，再更新；安装与升级细节见 [INSTALL.md](INSTALL.md)。

## 开发

```bash
npm install
WEIBO_CONSOLE_LICENSE=off npm start   # 开发模式：不校验激活
```

浏览器打开 `http://localhost:4178`。同一 Wi-Fi 下的手机使用启动日志显示的局域网地址。访问口令首次启动时生成在 `data/access-token`，也可以运行：

```bash
npm run token
```

进入网页后：

1. 点击“添加账号并扫码登录”，在本机窗口扫码；程序自动确认登录并使用微博昵称命名。已有有效登录会直接复用。
2. 超话默认固定为苏新皓。
3. 在共享文案库录入文字（可分组），所有账号随机共用；发帖和评论所选文案组内都至少需要 2 条不同且启用的文案，不足时开始运行会提示。
4. 在任务页调整操作段、数量、筛选策略和间隔；发帖和评论可分别添加随机表情、顺序数字并选择位置。

程序关闭 Chrome 或切换账号时会保留各自的登录目录，不会主动退出微博。请勿复制、同步或提交 `data/`，其中包含可用于登录的浏览器资料。

## 激活与分发

- 维护者用 `npm run license -- --user 张三 --token 你的口令` 生成激活码（私钥只在维护者本机 `~/.weibo-console/license-key.pem`）。
- 分发时把仓库地址给对方的 agent，激活码与访问口令单独发给本人；安装程序不会显示口令。
- 未激活时服务只放行激活页，业务接口一律 `license_required`。

## 运行规则

- 同时只启动一个自动化 Chrome，账号按超话依次处理。
- “仅零评论”在扫描到评论数为零时立即提交，不做第二次检查。
- 没有符合条件的帖子时持续等待，直到出现候选或你暂停、停止任务。
- 普通发帖、评论结果无法确认时标为“待核对”并继续后续步骤，不自动重复发送；验证码、网络或页面故障按各自恢复流程等待，用户手动暂停后不会自动继续。
- 账号被判定“频繁”时，该账号同类操作冷却 1 小时；被“禁言”时，该账号的发帖和评论 24 小时内跳过；只影响同一账号的对应操作，其他账号和签到照常进行。
- 详细运行记录保留 10 天后清理（启动时执行），每日汇总计数永久保留；账号、文案、任务配置不受影响。保留天数可用环境变量 `WEIBO_CONSOLE_RETENTION_DAYS` 调整。
- 登录失效或 UID 不符时跳过对应账号；验证码进入待验证队列；网络或页面加载故障保留进度等待恢复。分区不存在或页面结构无法识别时保留错误记录，不猜测目标或重复提交。
- 用户手动暂停或停止的任务不会在重启后自动继续；意外中断的任务会自动恢复。中断时正在提交的操作会转为待核对。
- 发帖与评论的数字序号独立保存，跨账号、任务和重启延续。

## 登录自启

安装脚本默认安装自启；也可手动：

```bash
npm run install-service     # Mac: launchd；Windows: 计划任务
npm run uninstall-service
```

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `WEIBO_CONSOLE_PORT` / `WEIBO_CONSOLE_HOST` | 监听端口 / 地址（默认端口 4178） |
| `WEIBO_CONSOLE_DATA_DIR` | 数据目录（默认 `data/`） |
| `WEIBO_CONSOLE_RETENTION_DAYS` | 详细记录保留天数（默认 10） |
| `WEIBO_CONSOLE_NOTIFY=off` | 关闭系统通知（测试用） |
| `WEIBO_CONSOLE_LICENSE=off` | 关闭激活校验（仅开发用） |
