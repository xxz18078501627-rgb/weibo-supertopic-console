# 制饼工坊 v1.1.1

制饼工坊是一个在本机运行的微博多账号管理工具。账号登录信息保存在本机，不经过服务器；统一管理签到、发帖、原创、评论和转赞评任务。

## 下载与安装

- Apple 芯片 Mac：下载 `weibo-console-1.1.1-mac-arm64.dmg`
- Intel 芯片 Mac：下载 `weibo-console-1.1.1-mac-x64.dmg`
- Windows 10/11 x64：下载 `weibo-console-1.1.1-windows-x64.exe`

从 [GitHub Releases](https://github.com/xxz18078501627-rgb/weibo-supertopic-console/releases/latest) 下载。安装不需要管理员权限，也不需要提前安装 Node。

安装包没有 Apple 公证和 Windows 代码签名。macOS 第一次打开时可能提示“无法验证开发者”，Windows 可能提示 SmartScreen，按对应教程放行一次即可。

- [Mac 安装与更新教程](docs/手动安装与更新-Mac.md)
- [Windows 安装与更新教程](docs/手动安装与更新-Windows.md)
- [通用安装说明](INSTALL.md)

安装完成后浏览器会自动打开 <http://localhost:4178>。首次进入时输入激活码和访问口令，再到“账号”页扫码登录微博。

## v1.1.1 新功能与改进

- 工作台新增“原创”：直接在微博主页输入文案并发布，不需要选择超话；原创文案、分组、记录和统计与发帖分开管理。
- 同一账号连续评论时复用同一个浏览器和超话页面，减少重复打开浏览器和重复加载；配置的评论间隔保持不变。
- 发帖提交会核对是否真的产生发布请求，识别“看起来点过、实际没有发出”的情况；确认发布成功后立即结算验证卡。
- 发帖、原创、签到、评论和转赞评的人工验证窗口保持可见并自动最大化；验证完成后下一张卡立即可以处理。
- 转发和内赞验证支持失败后再次验证；只有实际动作成功后才显示验证通过。
- 外赞已经点过时记为跳过；微博明确提示操作频繁时记为跳过，不再误计为待核对。
- 修复记录页“当日汇总”被挤成两行，以及账号页分组、登录状态和限制标签不对齐的问题。
- 继续保留断网暂停、页面故障恢复、每日 23:59 截止、待核对复核和应用内更新。

## 系统要求

- macOS 12 或更高版本；支持 Apple 芯片和 Intel 芯片。
- Windows 10/11 x64。暂不提供 Windows ARM64 安装包。
- 至少 1 GB 可用硬盘空间，能够访问 GitHub 和微博。

## 更新

1. 暂停正在运行的任务，结束扫码登录和人工验证。
2. 打开 <http://localhost:4178>，点击左侧“更新”。
3. 点击“检查更新”，下载 v1.1.1。
4. 保持“更新后重启”开启，点击“更新并重启”。
5. 页面重新打开后，健康接口中的版本应为 `1.1.1`。

账号、文案、任务、记录、激活状态和微博登录目录都会保留。任务、扫码或人工验证仍在使用时，可以提前下载，但不会应用更新。

## 数据与备份

- Mac：`~/Library/Application Support/ZhibingStudio/data`
- Windows：`%LOCALAPPDATA%\ZhibingStudio\data`

备份前先暂停任务，然后完整复制 `data` 文件夹。该文件夹包含登录状态和访问资料，不要上传网盘、发送给他人或提交到 GitHub。

## 常见问题

- **页面打不开**：等待几秒后刷新；仍无法打开时，在安装目录运行 `service.mjs status`。
- **端口 4178 被占用**：先确认是否为本软件的旧服务，不要强制结束未知程序。
- **Mac 提示无法验证开发者**：右键“一键安装.command”选择“打开”，再到“系统设置 → 隐私与安全性”点击“仍要打开”。
- **Windows SmartScreen 拦截**：点击“更多信息”，再点击“仍要运行”。
- **更新按钮不可用**：先暂停任务，结束扫码登录和人工验证。
- **校验失败**：删除下载文件，从官方 Release 重新下载，不要绕过 SHA256 校验。
